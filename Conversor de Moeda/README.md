# 💱 Conversor de Moedas em Python

Um aplicativo de linha de comando (CLI) simples e eficiente desenvolvido em Python para realizar conversões de moedas em tempo real consumindo dados atualizados da [AwesomeAPI](https://docs.awesomeapi.com.br/api-de-moedas).

---

## 🚀 Funcionalidades

- 🔄 **Cotação em tempo real:** Consulta de dados atualizados via requisição HTTP à API.
- 💱 **Suporte a múltiplas moedas:** Permite conversões entre USD, BRL, EUR, GBP, BTC, ARS e diversas outras moedas.
- 🛡️ **Tratamento de erros:** Validação de entradas numéricas do usuário e tratamento de falhas de conexão de rede.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- **[Requests](https://requests.readthedocs.io/):** Biblioteca para consumo de APIs REST.
- **AwesomeAPI:** API pública e gratuita de cotações financeiras.
