# 📁 Organizador Automático de Arquivos em Python

Um script utilitário desenvolvido em Python para automatizar a organização de arquivos em qualquer diretório (como a pasta de Downloads), categorizando-os e movendo-os automaticamente para subpastas com base em suas extensões.

---

## 🚀 Funcionalidades

- 🗂️ **Categorização Automática:** Separa arquivos por tipos (Imagens, Documentos, Códigos, Compactados, Instaladores, Áudios/Vídeos e Outros).
- 🛡️ **Proteção contra Sobrescrita:** Verifica se o arquivo já existe na pasta de destino antes de movê-lo.
- 🎯 **Caminho Dinâmico:** Permite organizar qualquer diretório informado pelo usuário ou o diretório atual onde o script está sendo executado.
- ⚙️ **Sem Dependências Externas:** Desenvolvido utilizando apenas módulos nativos do Python.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- Módulos nativos: `os`, `shutil` e `pathlib` (manipulação avançada de caminhos e arquivos no sistema operacional).
