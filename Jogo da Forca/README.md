# 🪓 Jogo da Forca (Hangman Game) em Python

Um clássico jogo da forca interativo executado diretamente no terminal, com visualização progressiva do bonequinho em arte ASCII a cada tentativa incorreta.

---

## 🚀 Funcionalidades

- 🎨 **Desenho em ASCII:** Renderização do boneco na forca atualizada a cada erro.
- 🔀 **Palavras Aleatórias:** Seleção sortida de termos a cada nova partida.
- 🧹 **Limpeza Automática de Tela:** O terminal é limpo a cada jogada para manter a interface organizada.
- 🛡️ **Validação de Entradas:** Impede palpites repetidos, números ou múltiplos caracteres.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- Módulos nativos: `os` (controle do sistema/terminal) e `random` (sorteio de palavras).
